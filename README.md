# ANODHAS Handy · Windows

Отдельная сборка Handy 0.9.8 для Windows x64 с названием, идентификатором и значком ANODHAS. Приложение и настройки macOS не используются и не изменяются.

## Сборка

Actions → ANODHAS Handy Windows EXE → Run workflow. Результат — архив артефактов с установщиками EXE (NSIS) и MSI. Публичный релиз не создаётся.

Исходная версия: [cjpais/Handy](https://github.com/cjpais/Handy), MIT, зафиксированный коммит `14f6f0d31cb22a4268acfbddba3052820fd0a06e` (v0.9.8). Сборка использует upstream-процедуру с минимальными изменениями для ANODHAS. Исходники прежних индивидуальных изменений Mac-версии не сохранились в найденном комплекте; полное совпадение таких изменений не заявляется.

## Настройка Windows

После установки разрешите доступ к микрофону, выберите устройство и загрузите модель Parakeet v3 Q4 в интерфейсе. Проверьте горячую клавишу и вставку результата в Блокнот. Модель распознавания загружается отдельно при первом запуске. Для первоначальной установки WebView2 и загрузки модели может требоваться интернет.

Собственный сертификат подписи Windows не подключён. Автообновление из оригинального Handy отключено, чтобы оно не заменило ANODHAS-версию.

## Проверки

Процесс сборки проверяет библиотеки, тихую установку EXE, распаковку MSI и запуск установленного приложения с `--list-devices`. Проверка микрофона, диктовки и вставки текста на реальном компьютере Windows остаётся отдельной пользовательской проверкой.
