# ANODHAS Handy для Windows

Открываемый комплект сборки ANODHAS Handy 0.9.8 для Windows x64: исходная версия Handy зафиксирована по коммиту, изменения ANODHAS и упаковка описаны непосредственно в workflow. Репозиторий содержит рецепт сборки и изменения, а полный исходный код приложения берётся из [cjpais/Handy](https://github.com/cjpais/Handy/tree/14f6f0d31cb22a4268acfbddba3052820fd0a06e).

## Текущая версия с моделью

Обычный установщик NSIS включает модель Parakeet TDT v3 Q4_K_M. В пользовательском комплекте нет PowerShell и вложенных установщиков. При первом запуске приложение размещает и выбирает встроенную модель. Для интерфейса требуется установленный Microsoft WebView2.

[Успешная сборка и проверки](https://github.com/zakras030997-byte/anodhas-handy-windows/actions/runs/39440297585) · [EXE для тестирования](https://github.com/zakras030997-byte/anodhas-handy-windows/actions/runs/39442749007)

EXE: `ANODHAS-Handy-0.9.8-Windows-x64-With-Model-Setup.exe`, 500 424 282 байта.
SHA256: `2d0a30ea13e19229af033c0fb05eff16a39c6664d60c424c199aec9cab1e6cb4`.

Версия без цифровой подписи, подготовлена для тестирования. В среде GitHub Windows прошли установка, проверка состава пакета и модели, распознавание тестовой записи при блокировке исходящей сети приложения и проверка Defender. Это не подтверждает отсутствие предупреждений Chrome/SmartScreen. Проверка микрофона, горячей клавиши и вставки текста остаётся за тестировщиком.

## Как собрать

1. Используйте ветку `native-model-installer`.
2. Изменение `.github/workflows/native.yml` или `build-native.yml` запускает Windows-сборку; доступен также ручной запуск, если он указан в workflow.
3. `native.yml` вызывает `build-native.yml`: скачивает закреплённый исходный коммит Handy, применяет изменения ANODHAS, проверяет и включает модель, собирает NSIS/MSI и выполняет проверки.
4. Артефакт сборки содержит EXE и MSI. `deliver-native.yml` выделяет неизменённый EXE из конкретного проверенного запуска; для новой версии обновите номер запуска.

Все изменения приложения, брендирование и проверка модели доступны в `.github/workflows/build-native.yml`. Скрипты PowerShell в GitHub используются только при сборке и проверках, на компьютере пользователя они не запускаются.

## Ограничения и предыдущие версии

Это отдельная Windows-сборка. Установленное приложение и настройки macOS не изменяются. Полное совпадение с прежними индивидуальными изменениями Mac-версии не заявляется. Автообновление из оригинального Handy отключено.

Старая упаковка из ветки `offline-ready` с вложенными установщиками заменена текущим обычным установщиком; она ранее была заблокирована Chrome и не предлагается для передачи тестировщику. Исторические результаты сохранены в ветке `installer-security-check`.
