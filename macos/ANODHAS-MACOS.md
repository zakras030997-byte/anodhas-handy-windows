# ANODHAS Handy macOS 0.9.9 — сохранённые исходники

Снимок локальной Mac-ветки от 7 ноября 2026 года. Версия в package.json и src-tauri/tauri.conf.json: 0.9.9; идентификатор приложения: ai.anodhas.handy. Сохранены исходники Rust/React, ресурсы интерфейса, локальный голосовой сервис и lock-файлы. Windows-сборка в корне репозитория сохраняется отдельно.

## Сборка и ограничения

См. [инструкцию upstream](BUILD.md). Нужны Rust с rustfmt/clippy, Bun, Xcode Command Line Tools и зависимости проекта. Перед сборкой выполните `python3 restore-upstream-assets.py`: скрипт восстановит 68 неизменённых публичных ресурсов из закреплённого коммита Handy с проверкой Git-хэша каждого файла. `python3 restore-upstream-assets.py --check` проверяет локальные ресурсы без сети и записи.

Обычная последовательность после восстановления ресурсов: `bun install --frozen-lockfile`, `bun run build`, `bun run tauri build`.

Этот коммит сохраняет исходники, а не готовый установщик и не обещание воспроизводимости прежнего DMG. Окружение Python, персональная библиотека голосов, пользовательские настройки, профили, крупные модели синтеза, node_modules, target, dist и кэши в Git не включены. Для голосовых функций требуется отдельно подготовленный совместимый Python runtime и модели; они не восстанавливаются одной командой сборки Tauri. Исходный BUILD.md описывает базовый Handy и не заменяет эту оговорку.

Перед публикацией выполнена проверка выбранных файлов Gitleaks: находок не обнаружено. Повторная полная сборка и функциональная проверка в этой операции не выполнялись. Проверки cargo fmt и cargo clippy не запустились: соответствующие компоненты отсутствовали в локальном Rust toolchain; Bun также не найден. Поэтому этот снимок не объявляется заново проверенным релизом.
