# ANODHAS Handy · macOS с голосовой студией

Версия ANODHAS 0.9.9 на основе Handy 0.9.8. Интерфейс «графит и янтарное стекло», отдельная генерация голоса, библиотека референсов, видимые папки хранения и контекстный словарь произношений. Исправлена запись Python-кэша внутрь подписанного приложения. Автообновление из upstream отключено.

## Две локальные модели

- Диктовка: handy-computer/parakeet-tdt-0.6b-v3-gguf, файл parakeet-tdt-0.6b-v3-Q4_K_M.gguf. Ревизия 85ac09ea12fc4b1112fa76810059364bc6adc9de, SHA-256 b68557be1e3c40207fd7c4bd9d63f1d3316b963f15325bfb0cc16a8bb0ffd181. CC-BY-4.0.
- Клонирование: mlx-community/Qwen3-TTS-12Hz-1.7B-Base-4bit, ревизия 37e955a1deb861c088ae5f3a67043185f3d1a60c, MLX 4-bit. Apache-2.0. Python 3.12.14, mlx-audio 0.6.2, MLX 0.32.4; полный список пакетов — requirements-voice.lock.

Установщик содержит публичные модели и локальную среду. Голосовые профили, записи, история и персональный словарь **в репозиторий и установщик не включаются**. Для генерации нужен собственный разрешённый референс. Добавление образцов не является дообучением. MLX-озвучка предназначена для Apple Silicon; поддержка Intel в этом комплекте не заявляется.

## Сборка

Нужны macOS ARM64, Bun, Rust, совместимый SDK и Python 3.12 с Pillow. build.sh получает исходники MIT-проекта cjpais/Handy по закреплённому коммиту 14f6f0d31cb22a4268acfbddba3052820fd0a06e и применяет handy-voice.patch. Исходное уведомление об авторстве не удаляется. Патч включает изменения бренда и голосовой студии; существующая Windows-сборка в корне репозитория остаётся отдельной.

Перед запуском задайте RUNTIME_DIR (локальный подготовленный каталог python/, model/ и site-packages/ либо venv/lib/python3.12/site-packages), PARAKEET_FILE (проверенный GGUF) и SDKROOT. Можно использовать публичную среду из Contents/Resources/voice-runtime уже собранного автономного приложения. requirements-voice.lock фиксирует пакеты, но не заменяет установку совместимого самостоятельного Python. Не используйте виртуальную среду с зависимостью от личного домашнего пути. Сборка откажется от обнаруженных ссылок на /Users/ внутри поставляемой среды.

Выполните bash macos/build.sh. Выходной DMG содержит приложение и ссылку Applications. Новое приложение читает прежний каталог ai.anodhas.handy, сохраняя настройки, историю и выбранную модель. Голосовые файлы лежат в его подпапке voice. На чистой установке Parakeet копируется из пакета при первом запуске, а Qwen и Python читаются прямо из ресурсов приложения. Существующие модель и настройки не перезаписываются.

## Проверки и ограничения

Пакет проверяет SHA-256 Parakeet, тип и 4-битную конфигурацию Qwen, переносимость путей, наличие лицензионных уведомлений и подпись приложения. model-manifest.json внутри приложения фиксирует версии и контрольные суммы весов. Локальные тесты: python3 -m unittest discover -s tests/voice в применённом исходном дереве; интерфейс — bun run build.

Это локальная ad-hoc-подпись, без Apple Developer ID и нотариального заверения. Возможные системные запросы следует проходить штатно; отключать Gatekeeper и защиту не требуется и не предлагается. Нативные разрешения микрофона и универсального доступа проверяются на целевом Mac. Успешное распознавание файла и генерация аудио не заменяют проверку микрофона, горячей клавиши и вставки текста. Старые приложения удаляются только после проверки замены и сохранения пользовательских данных; сам установщик чужие приложения и данные не удаляет.
